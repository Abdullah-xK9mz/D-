# وِصال — مشروع محادثات ويب

## الملفات
- `index.html`: صفحة إنشاء الحساب وتسجيل الدخول.
- `chat.html`: واجهة المحادثات.
- `style.css`: التصميم المتجاوب والألوان.
- `config.js`: إعدادات Supabase ورابط واجهة الخادم.
- `api.js`: الاتصال الآمن بواجهة الخادم.
- `auth.js`: منطق التسجيل وتسجيل الدخول.
- `chat.js`: المحادثات والبحث وإرسال الرسائل والملف الشخصي.

## التشغيل
1. فك ضغط الملف.
2. اترك الملفات السبعة في مجلد واحد كما هي.
3. افتح `index.html` للتجربة، أو شغّل مجلد المشروع من خلال خادم صفحات ثابتة.
4. أنشئ حسابًا باسم مستخدم فريد وكلمة مرور لا تقل عن 8 أحرف.
5. لكي تتواصل مع شخص آخر، يجب أن يفتح هو نفس رابط الموقع وينشئ حسابًا، ثم تبحث عنه باسم المستخدم.

## النشر العام
ملفات الواجهة موجودة داخل هذا الأرشيف، لكن لم يتم رفعها إلى استضافة عامة بعد. حتى يستطيع أي شخص فتح الموقع من رابط، ارفع محتويات المجلد إلى استضافة صفحات ثابتة مثل GitHub Pages أو Netlify أو Vercel. يجب أن تكون ملفات HTML وCSS وJavaScript في المسار نفسه.

## الخدمات الخلفية
تم تجهيز مشروع Supabase وربط الجداول والخادم الخلفي `wasla-api`. مفتاح النشر الموجود في `config.js` هو Publishable Key مخصص للواجهة. لا تضف أبدًا `service_role` أو أي Secret Key إلى ملفات المتصفح.

## المزايا الحالية
- إنشاء حساب باسم ظاهر واسم مستخدم وكلمة مرور.
- تسجيل الدخول باسم المستخدم وكلمة المرور.
- جلسة دخول محفوظة على الجهاز.
- البحث عن المستخدمين حسب بداية اسم المستخدم.
- محادثات مباشرة بين حسابين.
- إرسال واستقبال الرسائل النصية مع تحديث دوري كل 3 ثوانٍ.
- قائمة محادثات ومعاينة آخر رسالة.
- تعديل الاسم الظاهر والنبذة الشخصية.
- واجهة متجاوبة مع الهواتف والكمبيوتر.

## حدود النسخة الحالية
هذه نسخة أولى عملية للمحادثات النصية. لا تتضمن بعد مكالمات الصوت والفيديو، رفع الصور والملفات، المجموعات، حالات القصص، إشعارات الهاتف الفورية، أو تأكيد القراءة الحقيقي. التحديث الحالي دوري وليس WebSocket فوريًا.
